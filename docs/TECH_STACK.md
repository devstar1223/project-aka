# 기술 지도

프로젝트에서 실제로 선택해 사용 중인 기술과 그 이유를 역할별로 기록한다.
아직 필요하지 않아 결정하지 않은 기술은 기록하지 않는다.

각 항목은 아래 형식으로 추가한다.

```md
### 기술 또는 도구 이름

- 역할: 이 프로젝트에서 무엇을 담당하는가
- 선택: 사용 중인 버전, 도구, 또는 방식
- 이유: 현재 프로젝트에서 이 선택이 적절한 이유
- 상태: 검토 중 | 사용 중 | 대체됨
- 재검토: 어떤 상황에서 다시 결정할 것인가
```

### React

- 역할: 브라우저에서 글쓰기 화면을 만든다.
- 선택: React
- 이유: 웹 프론트엔드 경험을 쌓고, 향후 React Native 학습과 연결할 수 있다.
- 상태: 사용 중
- 재검토: 웹 화면 구조가 복잡해져 별도 도구가 실제로 필요해질 때
