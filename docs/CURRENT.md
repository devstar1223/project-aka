# 현재 구현 목표

## 사용자 결과

사용자는 서버가 제공한 단어를 보고 글을 작성한 뒤 제출할 수 있다.
제출이 성공하면 작성 완료 메시지를 확인한다.

## 이번에 포함

### 웹

- 서버에서 단어 하나를 받아 화면에 표시한다.
- 해당 단어에 대한 글을 자유롭게 작성할 수 있다.
- 제출 버튼을 누르면 단어와 글을 서버에 전송한다.
- 저장 성공 시 작성 완료 메시지를 표시한다.

### 서버

- 단어 요청에 **고정된** 단어 하나를 응답한다.
- 전달받은 단어와 글을 DB에 저장한다.

### 실행 환경

- 웹, 서버, DB 모두 로컬에서 실행한다.

## 이번에는 하지 않음

- 날짜별 단어 선정과 단어 DB 관리
- 로그인과 사용자 구분
- 저장한 글 다시 보기
- AI 피드백
- 배포
