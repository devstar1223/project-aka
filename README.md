## Commit Convention

`emoji type: 변경 요약` 형식을 사용한다.

| Emoji | Type | 설명 |
| --- | --- | --- |
| ✨ | `feat` | 새 기능 추가 |
| 🐛 | `fix` | 버그 수정 |
| 📝 | `docs` | 문서 변경 |
| 🎨 | `style` | 코드 스타일·포맷 변경 |
| ♻️ | `refactor` | 리팩토링 |
| ✅ | `test` | 테스트 추가·수정 |
| 🔧 | `chore` | 설정·잡무성 변경 |
| ⚡ | `perf` | 성능 개선 |
| 📦 | `build` | 빌드·의존성 변경 |
| 👷 | `ci` | CI/CD 설정 변경 |
| ⏪ | `revert` | 이전 커밋 되돌리기 |

예시:

```text
✨ feat: 글 작성 화면 추가
📝 docs: 현재 구현 목표 추가
📦 build: React 의존성 추가
```
